# 2026-08-22 日报

今天把创作助手从「能对话」推进到「能看见智能体在干什么」，并按用户反馈把思考过程改成接近 Cursor 的可折叠时间线。

## 产出

- 侧栏创作助手形成完整一轮使用闭环：打开定位到最新消息、白底输入框、点选技能、发送后清标签、项目记忆需确认才保存。
- 用户消息改为白底深色字（靛蓝描边），不再用浅紫底加浅色字。
- 纠正「思考过程」定义：展示的是本轮编排步骤（开始处理、应用技能、请求模型、整理回复），不是大模型推理文本。没有可见正文时也会留下步骤和说明，而不是空白卡片。
- 思考过程展示改为 Cursor 式轨迹：生成中展开并显示「正在思考」；结束后收成一行「思考过程」，点开才看步骤。正文与思考块分区，不再用「完成 · 步骤名」编号列表混进回复。
- 助手回复开始渲染加粗、列表、标题等 Markdown，不再把 `**ae-ideate**` 这类标记原样堆在气泡里。
- 角色设定改为：对话生成完整草稿（含外观、服饰）后先回填左侧表单，对话里点「保存角色」才写入项目；保存记忆不再被理解成已经填好角色。
- 候选稿区默认改为中文标签摘要（姓名、定位、外观、服饰等），JSON 收到「查看原文」；复制仍是原文。
- 服饰卡不再把「普通眼镜」标成「角色名称」，短字段改成一行标签+值；思考过程下面的 JSON 字符串改为「草稿已放到下方候选稿」。
- 外观回填补齐身高、体型、外观特征：顶层字段会合并进表单；`175`/`thin` 不再把下拉框留空；「黑色」等中文颜色会映射色块，文本仍保留中文。模型若把 JSON 包成字符串，思考过程下面也不再当原文展示。
- 助手对话框对比度：服饰卡和候选稿改为浅色字配更深一层卡片底，避免深蓝底加深灰字。
- 已把上述行为写入开发者指南、用户角色说明、架构图谱和 AI 记忆库。
- 设置页改为对话/图片/视频三个连接面；对话走 Web 代理或 Tauri 原生 SSE；图片/视频优先用已保存连接。
- 多选技能改为「各技能结果都保留，文末只用本轮结论问一件事」，避免两套「请确认」让用户无法回答。
- 可选技能改为创作向适配，产品技能（澄清、草稿、记忆提案）始终在后台生效，写表单仍需确认。
- 同期还落地了设置连接面、对话传输与恢复、编辑器工作流真实性，以及项目创建时的 AI 上下文/灵感相关能力。这些都还在工作区未提交。
