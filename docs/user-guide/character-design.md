# 角色设计

> 第 4 步：创建角色设定卡 + AI 参考图

## 角色设定卡

每个角色包含：

| 字段   | 说明                    |
| ------ | ----------------------- |
| 姓名   | 角色名字                |
| 性别   | 男/女/其他              |
| 年龄   | 年龄段                  |
| 外貌   | 发型/服装/体态          |
| 性格   | 核心性格特征            |
| 标志   | 独特标识（疤痕/饰品等） |
| 参考图 | AI 生成的角色参考图     |

## AI 参考图生成

基于角色描述自动生成参考图：

```
输入: "叶文洁，中年女性，短发，穿着 60 年代军装，目光坚定"
输出: 角色参考图（ Seedance / Kling / vidu 生成）
```

## 角色一致性

::: tip VLM 比对
后续步骤（分镜/渲染）会使用 VLM（视觉语言模型）比对新生成图像与角色参考图，确保角色一致性 ≥ 0.85。
:::

## AI 创作助手回填

角色步骤可打开右侧「AI 创作助手」。生成完整草稿后，左侧「待确认角色草稿」会先填入姓名、外观、服饰；在对话里点「保存角色」才会写入已确认角色。「保存本轮记忆」不会填写角色表单。

身高如果是厘米数字会显示在输入框；体型 `thin`/`偏瘦` 会落到「纤细」。外观特征来自草稿的 `features` 或 `appearance.features`。
